# Private #139 media GUI session selection

The driver resolves the target account's GUI environment from one Hyprland inventory record on wayland-1. It requires a successful session query with exactly one matching seat session, an account-owned inventory PID whose process name is Hyprland, a nonempty compositor signature, and a runtime Wayland socket. It derives the complete environment, including a UTF-8 locale, with bounded readiness polling.

The focused test extracts and executes the production selector with owned command and filesystem fixtures. It checks the complete environment, missing and ambiguous compositor records, wrong ownership, failed inventory, missing and ambiguous seat sessions, a failed session query that still prints a row, a non-Hyprland process, and a missing socket. The Unix socket fixture leaves no helper process running. No SSH, live VM, or host process selection runs in these tests.

Executing the selector exposed two defects missed by the earlier stubbed-response checks: a session-query failure with output was accepted, and multiple seat sessions were reduced to the first. Both now have explicit status/count checks. Full ordered gates and actual wizard/panel/bar captures remain pending.
